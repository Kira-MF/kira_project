# JoJo Discord Bot

Discord бот по вселенной JoJo's Bizarre Adventure.

## Возможности

- 110+ стендов из частей 3-8
- Тиры: D / C / B / A / S / SS / SSS
- Эволюции через Requiem Arrow
- Вампирская эволюция через Stone Mask
- Прокачка способностей Tier 1->2->3
- Скрещивание стендов через Rokakaka
- Хранилище стендов (до 2 штук)
- Кейсы: Common / Rare / Epic / Legendary
- Магазин, квесты, работа
- Все ответы эфемерные (видит только ты)

## Установка

```
py -m pip install -r requirements.txt
```

## Настройка

Открой `bot.py`:
```python
TOKEN    = "твой токен от Discord Developer Portal"
GUILD_ID = ID_твоего_сервера  # для мгновенной синхронизации /команд
```

## Запуск

```
py bot.py
```

## Команды

| Команда | Описание |
|---|---|
| `/job` | Работа (кд: 30 мин) |
| `/search` | Найти кейс (нужно 3 работы) |
| `/crate` | Открыть кейс |
| `/arrow` | Использовать стрелу |
| `/stand` | Посмотреть стенд |
| `/inv` | Инвентарь |
| `/evolve` | Эволюция стенда (requiem/vampire) |
| `/upgrade` | Прокачать способность |
| `/rokakaka` | Скрестить стенды |
| `/storage` | Хранилище стендов |
| `/shop` | Магазин |
| `/quest` | Квесты |
| `/money` | Баланс |
| `/help` | Список команд |

## Файлы

| Файл | Описание |
|---|---|
| `bot.py` | Основной файл бота |
| `stands.py` | База стендов (110+) |
| `players.json` | База игроков (создаётся автоматически) |
